## ✨ What It Is

Official website of the **CEGESAN Educational Institution** in Cúcuta, Norte de Santander, Colombia. An admissions page and institutional information site covering preschool, primary, secondary, and high school.

**Live site:** https://www.cegesan.edu.co/

---

## 🎯 Features

| Section | Description |
|---------|-------------|
| **Hero** | Full-screen hero with statistics and 2026 admissions CTA |
| **Why CEGESAN** | Three pillars: academic excellence, values, culture |
| **Grades** | List of offered levels (preschool → high school) |
| **Admissions CTA** | Call-to-action block with WhatsApp button |
| **Footer** | Address, legal links, floating WhatsApp button |
| **WhatsApp** | Floating button for direct contact |

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Markup** | HTML5 semantic |
| **Style** | CSS3 vanilla (no framework) |

| **SEO** | Open Graph, Twitter Cards, JSON-LD `EducationalOrganization` |

## 🚀 Quick Start

No server needed. Open and go.

```bash
# Clone
git clone https://github.com/Holfkings/cegesan-site.git
cd cegesan-site

# Option A — open directly
# Double-click index.html or open in browser

# Option B — local server
python -m http.server 8000
# Open http://localhost:8000
```
